# Student Management System

A simple Python-based Student Management System that allows users to manage student records efficiently.

## Features

- Add Student
- View Students
- Search Student by ID
- Update Student Details
- Delete Student Record
- Store Data Using JSON File

## Technologies Used

- Python 3
- JSON

## Project Structure

student-management-system-python/

├── main.py

├── students.json

├── README.md

## How to Run

1. Clone the repository
2. Open terminal in the project folder
3. Run:

python main.py

## Learning Outcomes

- Python Functions
- Loops and Conditions
- Lists and Dictionaries
- File Handling
- JSON Data Storage
